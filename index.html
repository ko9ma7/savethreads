Threads 동영상 및 이미지 다운로드

공개된 Threads 게시물 링크를 붙여넣어 고화질 MP4 동영상과 이미지를 저장하세요.

사용 방법

1

링크 복사

Threads 앱이나 웹에서 저장하고 싶은 게시물의 공유 버튼을 눌러 링크를 복사합니다.

2

링크 붙여넣기

상단 입력창에 복사한 URL을 붙여넣고 다운로드 버튼을 클릭합니다.

3

파일 저장

추출된 비디오(MP4) 또는 이미지 목록에서 원하는 화질의 저장 버튼을 누릅니다.

자주 묻는 질문

비공개 계정의 게시물도 다운로드할 수 있나요?

아니요, 전체 공개된 Threads 게시물의 미디어만 추출 및 다운로드할 수 있습니다.

GitHub Pages에서 바로 동영상이 추출되나요?

GitHub Pages는 정적 웹 호스팅만 지원하므로 브라우저의 CORS 정책을 우회하기 위해 Cloudflare Workers 또는 별도의 백엔드 API 엔드포인트를 `script.js`에 연결해야 실제 크롤링이 동작합니다.
